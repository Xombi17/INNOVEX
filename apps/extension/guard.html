Why authorization must restart in the initiating app

PKCE links a secret verifier to a challenge; scopes and state are not part of that hash. Editing scopes can conflict with the app’s authorization transaction. Ask the initiating app to start a fresh request with reviewed scopes, fresh state and an appropriate verifier/challenge. A URL with security parameters removed is not a secure login replacement.
