# Phase 9 Plan 01: Live 4-Agent Defense Swarm Streaming & Interactive Triage Mesh

## Objective
Elevate ScopeBomb's Agent Operations Center into a real-time collaborative defense mesh where the 4 specialized AI agents (Sentinel, Threat Modeler, Red Team, Containment Commander) automatically stream their deliberation upon target selection, provide interactive prompt chips, and generate copyable incident briefs.

## Context
- `apps/web/src/components/AgentSwarmCenter.tsx`: Swarm frontend UI and interaction controller.
- `apps/web/src/app/api/agent-swarm/route.ts`: Swarm API endpoint with Gemini 3.x Flash and deterministic fallback.
- `apps/web/src/lib/agentSwarmTypes.ts`: Personas, roles, badges, and message types.

## Tasks
1. **Auto-Trigger & Progressive Streaming Simulation:**
   - Auto-initiate swarm consultation on scenario load so the user doesn't encounter an empty standby box.
   - Implement progressive streaming dispatch: Sentinel ➔ Threat Modeler ➔ Red Team ➔ Containment Commander with live status indicators.
2. **Interactive Triage Controls:**
   - Add dynamic prompt chips (`"Worst-case exploit?"`, `"Can this reach AWS?"`, `"Draft CISO report"`).
   - Add a one-click **"Copy Swarm Incident Brief"** button.
3. **Verification:**
   - Verify web build (`npm run build --prefix apps/web`).
   - Verify engine tests (`node --test tests/engine/*.test.ts`).
