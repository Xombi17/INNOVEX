# Plan: Phase 13 — OpenTelemetry Distributed Tracing, Verification Suite & Live Production Ship

## Objective
Implement native zero-dependency OpenTelemetry (OTel) distributed tracing across the full ScopeBomb pipeline (input ingestion, blast radius graph computation, 4-agent swarm consensus, and RFC 7009 multi-cloud invalidation). Verify the entire platform with all automated unit, contract, integration, and CDP headless browser test suites. Update Graphify and ship the final release to live production at `https://scopebomb.vercel.app`.

## Key Deliverables
1. **Zero-Dependency OpenTelemetry Core (`apps/web/src/lib/telemetry.ts`)**:
   - W3C Trace Context specification (`traceparent` header `00-${traceId}-${spanId}-${flags}`).
   - OpenTelemetry span creation with high-resolution timestamps, attributes, events, status, and parent linkage.
   - Traced operations:
     - `scopebomb.input.parse`: local config parsing, AST extraction, and scope categorization.
     - `scopebomb.graph.blast_radius`: BFS path traversal, 4 trust boundary transitions, edge propagation.
     - `scopebomb.swarm.consensus`: Gemini 3.x Flash 4-agent parallel dispatch and incident synthesis.
     - `scopebomb.containment.rfc7009`: Multi-cloud invalidation, active verification probe, audit receipt generation.
2. **OTel Trace Exporter Route (`apps/web/src/app/api/traces/route.ts`)**:
   - `GET /api/traces`: Exposes in-memory trace spans conforming to the OpenTelemetry `ResourceSpans` JSON schema.
   - `POST /api/traces`: Accepts client-side trace events from browser components.
3. **Route & Component Instrumentation**:
   - Instrument `/api/agent-swarm/route.ts` with OTel spans.
   - Instrument `/api/remediate/route.ts` with OTel spans.
   - Display active trace status badge in the header/landing page.
4. **End-to-End Verification**:
   - Core Engine tests: `node --test tests/engine/*.test.ts` (30/30).
   - Python contract verification: `python3 contracts/verify_contracts.py`.
   - Web tests: `npm run test --prefix apps/web` (36/36).
   - Production Next.js build: `npm run build --prefix apps/web` (0 errors).
   - Headless Chrome CDP test: `npm run test:browser --prefix apps/web`.
5. **Graphify & Production Release**:
   - Update knowledge graph with `graphify update .`.
   - Verify deployment to `https://scopebomb.vercel.app`.
