# Plan: Phase 12 — High-Conversion Product Landing Page & Multi-Tab Web Architecture

## Objective
Re-architect the ScopeBomb web application from a cluttered single-page workbench into an enterprise-grade SaaS website matching the clean, modern UI/UX, faint gradients, and design guidelines of DeepSeek and Harness. Deliver a high-conversion public Landing Page (`/` Overview), a dedicated Threat Cockpit tab, an Autonomous SOC Swarm tab, a Containment & RFC 7009 tab, and a Developer Tools (CLI & MV3 Extension) hub.

## Key Deliverables
1. **Design System Tokens & Gradients (`globals.css` & `uiTokens.ts`)**:
   - DeepSeek/Harness dark slate canvas (`#07090e` / `#0a0d14` background, `#0d111a` / `#111625` surface cards).
   - Electric Blue (`#3b82f6` / `#4d6bfe`) & Cyber Cyan (`#00d2b4` / `#06b6d4`) accents.
   - Faint ambient radial and linear gradients for depth without visual noise.
   - Subtle glowing border treatments on interactive cards and status badges.
2. **High-Conversion Product Landing Page (`LandingPage.tsx`)**:
   - Punchy developer hook: "One rogue AI permission can compromise your entire cloud stack. RFC 7009 Disconnect only revokes the front door."
   - Interactive Attack Chain Domino visual teaser.
   - 5 Core Capability Pillars (Domino Blast Simulator, 4-Agent Defense Swarm, RFC 7009 Containment, MV3 Pre-Consent Guard, CI/CD Gate).
   - "Status Quo (OAuth Disconnect) vs ScopeBomb" comparison matrix.
   - Real-world Incident Case Studies (Slack AI exfil, MCP token theft, Claude Coworker repo read).
   - Dual Call-to-Action: `[ 🚀 Launch Threat Cockpit ]` & `[ 💥 Detonate Live Exploit ]`.
3. **Multi-Tab Architecture (`ScopeBombArena.tsx`)**:
   - Seamless top-level navigation:
     - `Overview` (Product Landing Page)
     - `Threat Cockpit` (Blast Radius Simulator & Scanner)
     - `Defense Swarm` (Full-view 4-Agent SOC Deliberation)
     - `RFC 7009 Remediation` (Multi-Cloud Containment & Active Verification Probes)
     - `CLI & Extension` (Developer Tools & GitHub Action Gate)
   - Zero-reload reactive tab switching with URL query synchronization (`?tab=...`).
4. **Developer Tools & Extension Hub (`ToolsCenter.tsx`)**:
   - Interactive CLI runner preview: `npx @scopebomb/cli scan . --fail-on-risk 80`.
   - Reusable GitHub Action configuration with 1-click copy.
   - Chrome MV3 Pre-Consent Guard installation & PKCE security architecture explanation.
5. **Quality & Test Gates**:
   - `npm run build --prefix apps/web` compiles with 0 errors.
   - Core engine tests pass `30/30`.
   - Contract verification passes `verify_contracts.py`.
   - Graphify updated with `graphify update .`.
