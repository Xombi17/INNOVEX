# Phase 11 Plan 01: Enterprise CI/CD Pipeline Gate & Standalone CLI Scanner (`scopebomb-cli`)

## Objective
Package ScopeBomb as a standalone CLI tool and reusable GitHub Action CI/CD security gate that blocks pull requests introducing dangerous cascading scopes or uncontained MCP tool configs.

## Context
- `packages/engine/cli.ts`: Core scan engine (frozen read-only baseline).
- `action.yml`: GitHub Action definition at repository root.
- `.github/workflows/scopebomb-gate.yml`: Automated CI workflow demonstration.
- `bin/scopebomb`: Standalone executable CLI entry point with rich terminal output, `--fail-on-risk`, `--markdown`, and `--json`.

## Tasks
1. **Create CLI Executable (`bin/scopebomb.mjs`):**
   - Provide command `scopebomb scan [directory]` with flags:
     - `--json`: Emit full RFC 7009 compliant AuditReport JSON.
     - `--fail-on-risk <N>`: Exit with code 1 if `max_risk_score >= N` (CI gate mode).
     - `--markdown`: Generate PR comment summary with blast-radius chain.
     - Default: High-craft colorized ASCII terminal report.
2. **Create Reusable GitHub Action (`action.yml`):**
   - Define inputs (`path`, `fail-on-risk`, `comment-on-pr`).
   - Run `scopebomb scan` and post step summary.
3. **Add Sample CI Workflow (`.github/workflows/scopebomb-gate.yml`):**
   - Run on `push` and `pull_request` to demonstrate automated non-human identity firewalling in CI.
4. **Verification:**
   - Test CLI directly with `node bin/scopebomb.mjs --help`, `node bin/scopebomb.mjs scan .`, and `node bin/scopebomb.mjs scan . --fail-on-risk 50`.
   - Verify engine tests and Next.js build.
