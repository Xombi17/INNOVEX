# Phase 8 Plan 01: Instant Attack Detonator & High-Impact Cockpit UI

## Objective
Transform ScopeBomb's front-facing experience from an academic, text-dense compliance checklist into an interactive, visually stunning security cockpit that delivers an undeniable "Aha!" moment in under 5 seconds.

## Context
- `apps/web/src/components/ScopeBombArena.tsx`: Main page layout and step orchestration.
- `apps/web/src/components/DominoGraph.tsx`: Blast radius graph component, currently buried in an accordion.
- `apps/web/src/components/Step2AttackPath.tsx`: Contains the collapsed `<details>` that hides the Domino Graph.
- `apps/web/src/components/AgentSwarmCenter.tsx`: The 4-agent collaborative defense center.

## Tasks
1. **Un-box the Domino Blast Graph onto Primary View:**
   - Remove the `<details>` wrapper in `Step2AttackPath.tsx` so the Domino Graph is immediately rendered front-and-center.
   - Embed an interactive preview directly on the Welcome/Hero section so new visitors see it immediately without hunting.

2. **Add "Detonate Scope Bomb" Interactive Scrubber:**
   - Add a high-visibility button: `[  Detonate Attack Simulation ]` with animated step-by-step token exfiltration (`Agent` ➔ `Drive` ➔ `GitHub` ➔ `AWS`).
   - Create neon pulse and particle highlights for active attack nodes.

3. **Prominent "Naive Disconnect vs. Surgical Containment" Toggle:**
   - Make the simulation mode toggle prominent with visual badge indicators showing which nodes survive during a naive disconnect.

4. **Streamline Copy and Replace Jargon:**
   - Replace defensive legalistic caveats with punchy developer problem statements:
     *"Why standard disconnect buttons fail to stop stolen cloud tokens."*

## Verification
- Local Next.js build passes (`npm run build --prefix apps/web`).
- Zero console errors in browser.
- Graph visualizes immediately on load.
