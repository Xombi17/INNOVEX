## 2. Invariant & Security Verification

1. **RFC 7009 & GitHub Grant Revocation Nuance:**
   - Naive single revocation (`HTTP 200 OK`) is never represented as proof of containment; multi-issuer plan covers secondary tokens and service account keys.
   - GitHub `DELETE /applications/{client_id}/grant` with Basic authentication and 204 semantics preserved.
2. **PKCE RFC 7636 Pre-Consent Invariant:**
   - Pre-consent evaluation sets `safe_replacement_url: null`. URL parameters are never rewritten in-flight.
3. **SSRF & Data Privacy Invariant:**
   - `/api/scan-repo` only queries `api.github.com` and `raw.githubusercontent.com`.
   - All tokens, keys, and credentials are masked on the server before report synthesis.
   - AI triage receives only structured risk counts and redacted capability strings; zero private secret values are transmitted.
