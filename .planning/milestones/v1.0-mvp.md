## Known Usability Gaps Carry-Forward (Trigger for v1.1)

User evaluation of `v1.0` (`ea28931`) identified critical first-impression and hackathon competitiveness issues:
1. **Information overload & broken mental model:** Landing page stacks ~1,171 words (~3.6 screens) vertically under overlapping sidebar tabs (`Blast simulator` duplicates `Remediation plan` and `PKCE guard`), mixing 5 cryptic incident titles directly under the mode nav.
2. **Primary scanner hidden:** Custom URL / `.mcp.json` input starts collapsed (`scannerOpen: false`), making first-time visitors think the app is static text.
3. **Jargon-first headlines:** Leads with HTTP 200 / RFC 7009 protocol framing before a new user understands what the app even checks.
4. **Missing interactive PS 05 proof points:** No live public GitHub repo scanner, no plain-English AI triage explainer (`ai_explainer_used: false`), generic provider strings (`P2`/`P3`) lacking concrete CLI kill-switch commands, and no downloadable MV3 extension zip + interactive fake-consent test sandbox on Vercel.
