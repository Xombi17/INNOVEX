# Five-person usability session kit

Status: **Pending — no participants tested.** Next action: a human facilitator recruits five developers unfamiliar with ScopeBomb, obtains consent for anonymous notes, and runs this protocol individually. Do not contact participants without the user's instruction. Do not use generated participants or infer human success from browser checks.

Use the [existing targets](../UX-VALIDATION.md#human-study-pending). Allow approximately 15 minutes per participant. Record aliases P01–P05 only, session date, build commit, browser/OS and input method. Do not record personal account details, secrets or identifying quotations. Ask permission separately before recording audio/video; written anonymous notes suffice.

Facilitator opening: “We are testing the tool, not you. Please think aloud. Use only the supplied examples. I will observe before helping; you can stop at any time.” Do not explain the product or demonstrate controls. Start each session with a fresh tab on the welcome page. Time tasks from the end of the prompt to the participant's answer or completion. Record the first attempt before any help. Stop scoring a task after two minutes; subsequent help is an intervention, not unaided success.

| Task | Read verbatim | Observe before helping |
| --- | --- | --- |
| Ten-second comprehension | After ten seconds: “What does this tool do, and what would you choose first?” | Their explanation and first choice; no product introduction before scoring. |
| Explicit sample choice | “Explore an example and explain whose accounts it describes.” | Time from this prompt through reaching example findings and explaining their provenance; distinguish illustration from own accounts. |
| Local input | “Use this supplied configuration to check it in the tool.” | How they find the input control, supply text and recover from errors; never offer a live secret. |
| Evidence and uncertainty | “Show what was found, what could follow, and what is still unknown.” | Source, placeholder/reference distinction, conditional consequences and unverified credential validity. |
| Provider action | “Find one practical next action and explain who can do it.” | Concrete action at the appropriate issuer and correct actor; no execution in a real account. |
| Meaning of progress | “Mark a review action done, preview the outcome, and explain what has changed.” | They understand that the tool has performed no remediation and has not verified containment. |
| Practical value | “What decision did this help you make? How do you do that today, and when would you use it again?” | Participant's own decision and a short quotation; absence of a useful decision is a result. |
